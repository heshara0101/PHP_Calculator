# PHP Calculator

A modern calculator built with HTML, CSS, JavaScript, and PHP.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Responsive Design

## Technologies

- PHP
- HTML5
- CSS3
- JavaScript

## Screenshot

![Calculator](Calculator.png)

## Run Locally

1. Install XAMPP.
2. Copy the project to `htdocs`.
3. Start Apache.
4. Visit:

```
http://localhost/calculator/index.php
```
